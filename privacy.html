Lily 개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-10-16

1. 수집하는 정보

Lily는 사용자가 허용하면 Google Calendar API(calendar.events)로 사용자 본인 캘린더에 새 일정을 추가합니다. 그 밖의 Google 사용자 데이터는 사용하지 않습니다.

2. 저장 위치

로그인 토큰과 설정은 사용자 PC의 Windows 자격 증명 관리자에만 저장됩니다. Lily에는 별도 서버가 없으며, 데이터를 외부로 보내지 않습니다(Google API 호출 제외).

3. 공유·판매

Google 사용자 데이터는 누구와도 공유하거나 판매하지 않으며, 광고에 쓰지 않습니다. Lily의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 해제·삭제

언제든 Google 계정 → 타사 앱 액세스에서 Lily 권한을 해제할 수 있습니다. 해제하거나 Lily를 지우면 PC에 저장된 토큰도 더 이상 쓰이지 않습니다.

English summary

With the user's permission, Lily adds events to the user's own Google Calendar via the Calendar API (calendar.events). Tokens are stored only in Windows Credential Manager on the user's PC; Lily has no server and sends no data anywhere except Google's APIs. Google user data is never shared, sold, or used for advertising. Lily's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
