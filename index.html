Lily

Lily는 개인용 Windows 데스크톱 비서 프로그램입니다. 개발자 본인 한 사람만 자기 PC에서 사용합니다.

Lily is a personal Windows desktop assistant, used only by its developer on their own PC.

Google 캘린더 사용 / Google Calendar use

  • 사용자 본인의 Google 캘린더에 일정을 추가하기 위해 Google Calendar API(calendar.events)를 사용합니다.
  • Lily uses the Google Calendar API (calendar.events) only to add events to the user's own calendar.
